为什么 QCP 更适合游戏

TLB 语义交付
不是字节级全可靠，而是按消息语义交付
REALTIME: 最新覆盖 · CRITICAL: deadline 内有界 ARQ
BATCH: 强可靠 · 超时放弃，走预测
三通道语义
REALTIME: 移动/AOI（不可靠，SeqID 去旧）
CRITICAL: 射击/技能（Fast NACK + 1-RTT）
BATCH: 聊天/交易（ARQ + ACK）
5G/6G 多路径
WiFi + 5G Race / Fallback
PathID 映射网络切片
0-RTT 路径切换 · MEC 边缘锚点
Recovery Policy（按需）
多路径 Race > Fast NACK > Network Coding > ARQ
非 FEC-first，仅在 burst 丢包时临时启用纠删
Zero-Copy + Lock-Free
预分配 64KB 内存池
CAS 无锁队列 · 100K+ 并发
AI 拥塞控制
动态选择 Recovery Policy
预测 RTT/丢包 · 路径建议 · 冗余率（若启用）
vs KCP
