# QCP Protocol Specification v1.0

**Quick Connect Protocol — 2026 游戏级 UDP 可靠传输协议**

---

## 1. 本质区别：QCP ≠ KCP

```
KCP: UDP + TCP思维 = ARQ重传 = 每个丢包都卡
QCP: UDP原生 + 游戏思维 = FEC纠错 = 丢包几乎无感
```

**KCP 是在 UDP 上复刻 TCP，QCP 是为游戏场景从零设计。**

---

## 2. 协议层创新

### 2.1 FEC-First 可靠性模型

```
KCP: 可靠性 = ARQ (丢包 → 重传 → 等待)
QCP: 可靠性 = FEC (丢包 → 实时解码 → 完成)

┌─────────────────────────────────────────────────┐
│  KCP: 丢包 → 8-20ms 重传延迟                   │
│  QCP: 丢包 → 1μs FEC解码                       │
└─────────────────────────────────────────────────┘
```

### 2.2 自适应 FEC 编码

```
根据实时网络状况动态调整冗余率:

网络状况      FEC冗余    冗余开销
──────────────────────────────────
优秀 (<1% loss)    5%     +5% 带宽
良好 (1-5% loss)   10%    +10% 带宽
一般 (5-10% loss)  20%    +20% 带宽
恶劣 (10-20% loss) 30%    +30% 带宽
极差 (>20% loss)   40%    +40% 带宽
```

### 2.3 可变长包头

```
KCP: 固定 24 bytes 包头
QCP: 可变 4-16 bytes 包头

基础头 (4 bytes):
┌─────────┬─────────┐
│ type(1) │ stream(1)│ seq(2)  │
└─────────┴─────────┘

扩展头 (按需):
┌─────────┬─────────┬─────────┐
│ fec_id  │ ts_diff │ pri(1)  │  +3 bytes
└─────────┴─────────┴─────────┘
```

### 2.4 三通道优先级调度

```
Channel 0: CRITICAL (射击/技能/关键帧)
  - 最高优先级
  - 零等待调度
  - FEC保护最强

Channel 1: REALTIME (移动/AOI/状态同步)
  - 正常优先级
  - 标准调度
  - 标准FEC

Channel 2: BATCH (聊天/日志/非关键)
  - 低优先级
  - 延迟容忍
  - 可降级FEC
```

### 2.5 无缝连接迁移

```
WiFi → 4G 切换:
1. 检测WiFi信号衰减
2. 预建立4G连接
3. 双路并行发送 (冗余包)
4. WiFi断开后4G无感接管
5. 0-RTT切换，玩家无感知
```

### 2.6 AI 拥塞控制

```
输入特征:
- RTT历史序列 (最近100个样本)
- 丢包率变化趋势
- 带宽利用率
- 时间特征 (游戏高峰期/低谷期)
- 多路径状态

输出:
- 最优发送速率
- 最优FEC冗余率
- 预测未来100ms网络状态
```

## 3. 数据流架构

### 3.1 Zero-Copy Ring Buffer

```
预分配64KB环形缓冲区:
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ P1│ P2│ P3│ P4│ P5│ P6│ P7│ P8│
└───┴───┴───┴───┴───┴───┴───┴───┘
      ↑ write     ↑ read

- 写入: 直接写入环形区，无拷贝
- 读取: 直接从环形区读取，无分配
- GC: 零压力
```

### 3.2 Lock-Free 队列

```
发送端: 原子CAS写入 → 无等待
接收端: 原子CAS读取 → 无等待
并发: 100K+连接无锁竞争
```

### 3.3 批量处理

```
10ms批次:
- 收集10ms内所有包
- 一次性FEC编码
- 一次性发送
- 系统调用: 100次/10ms → 1次/10ms
```

### 4.2 Go 绑定 (性能验证)

```go
import "github.com/neko233-com/qcp-lib-go/qcp"

// 创建连接
conn := qcp.Dial("game.example.com:9000")

// 设置优先级
conn.SetPriority(qcp.PRIORITY_CRITICAL)

// 发送数据 (零拷贝)
conn.Send(data)

// 接收数据
buf := make([]byte, 1024)
n, _ := conn.Recv(buf)
```

### 4.3 C# 绑定 (Unity)

```csharp
using QcpLib;

var conn = new QcpConnection("game.example.com", 9000);
conn.SetPriority(QcpPriority.Critical);
conn.Send(data);
byte[] buf = new byte[1024];
int n = conn.Receive(buf);
```

### 4.4 C++ 绑定 (UE)

```cpp
#include <qcp/qcp.h>

auto conn = qcp::Dial("game.example.com:9000");
conn->SetPriority(qcp::PRIORITY_CRITICAL);
conn->Send(data);
```
