# QCP

**Q**uick **C**onnect **P**rotocol — 2026 游戏高频战斗 UDP 传输协议

**强实时 + 数据正确 = 为游戏战斗而生**

---

## 核心需求

游戏高频战斗场景：
1. **强实时** — 射击、技能必须 < 50ms 响应
2. **数据正确** — 伤害值、技能效果不能错
3. **高频传输** — 每秒 100+ 包（移动、AOI、状态）

**不是"不能丢包"，是"关键数据保证正确，普通数据快速到达"**

## QCP 设计理念

### 1. 分层可靠性

```
┌─────────────────────────────────────────────────────────────┐
│                    QCP 分层可靠性                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Layer 1: FEC (即时恢复)                                    │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  冗余率: 20%                                        │   │
│  │  丢包 ≤ 20%: FEC 直接恢复，0 延迟                   │   │
│  │  适用: 移动、AOI、状态同步                          │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  Layer 2: ARQ (选择性重传)                                  │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  仅对关键数据启用                                    │   │
│  │  重传延迟: 1 RTT                                     │   │
│  │  适用: 射击命中、技能释放、伤害计算                  │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  Layer 3: Checksum (数据完整性)                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  CRC32 校验                                         │   │
│  │  保证包内容正确                                      │   │
│  │  错误包直接丢弃                                      │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2. 三通道优先级

```
┌─────────────────────────────────────────────────────────────┐
│                    QCP 三通道                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Channel 0: CRITICAL                                        │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  数据: 射击命中、技能释放、伤害值                    │   │
│  │  要求: 保证到达、数据正确                           │   │
│  │  FEC: 30% + ARQ 重传                                │   │
│  │  延迟目标: < 20ms                                   │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  Channel 1: REALTIME                                        │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  数据: 移动同步、AOI广播、状态更新                   │   │
│  │  要求: 快速到达、可丢失                             │   │
│  │  FEC: 20% (无ARQ)                                   │   │
│  │  延迟目标: < 30ms                                   │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  Channel 2: BATCH                                           │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  数据: 聊天、日志、非关键                           │   │
│  │  要求: 可靠、可延迟                                 │   │
│  │  FEC: 10% + ARQ                                     │   │
│  │  延迟目标: < 100ms                                  │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3. 数据正确性保证

```
┌─────────────────────────────────────────────────────────────┐
│                    数据完整性                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  发送端:                                                    │
│  ┌─────────┐   ┌─────────┐   ┌─────────┐                 │
│  │ 应用数据│ → │ CRC32   │ → │ FEC编码 │ → UDP            │
│  └─────────┘   └─────────┘   └─────────┘                 │
│                      ↓                                     │
│              ┌───────────────┐                             │
│              │ 每包附带校验和│                             │
│              └───────────────┘                             │
│                                                             │
│  接收端:                                                    │
│  ┌─────────┐   ┌─────────┐   ┌─────────┐                 │
│  │ UDP接收│ → │ CRC32   │ → │ FEC解码 │ → 应用            │
│  └─────────┘   └─────────┘   └─────────┘                 │
│                      ↓                                     │
│              ┌───────────────┐                             │
│              │ 校验失败→丢弃 │                             │
│              └───────────────┘                             │
│                                                             │
│  保证: 收到的包内容 100% 正确                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 战斗数据流

```
┌─────────────────────────────────────────────────────────────┐
│                    战斗数据流                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  玩家A射击 →                                               │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 1. 计算伤害值                                       │   │
│  │ 2. 附加 CRC32 (保证正确)                            │   │
│  │ 3. 标记为 CRITICAL (最高优先级)                      │   │
│  │ 4. FEC 编码 (30% 冗余)                              │   │
│  │ 5. UDP 发送                                         │   │
│  └─────────────────────────────────────────────────────┘   │
│                          ↓                                  │
│  网络传输 (可能丢包、延迟、乱序)                            │
│                          ↓                                  │
│  服务器接收 →                                               │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 1. UDP 接收                                         │   │
│  │ 2. CRC32 校验 (错误→丢弃)                           │   │
│  │ 3. FEC 解码 (恢复丢包)                              │   │
│  │ 4. 按 SeqID 排序                                    │   │
│  │ 5. 应用处理                                         │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 快速开始

### Go

```go
conn, _ := qcp.Dial("game:9000")

// 射击 - 关键数据，保证到达
conn.SendWithPriority(attackData, qcp.CRITICAL)

// 移动 - 实时数据，快速到达
conn.SendWithPriority(moveData, qcp.REALTIME)

// 接收
data, priority, _ := conn.Recv()
```

### C# (Unity)

```csharp
conn.SendWithPriority(attackData, QcpPriority.Critical);
conn.SendWithPriority(moveData, QcpPriority.Realtime);
var (data, priority) = conn.Receive();
```
